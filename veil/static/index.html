A privacy gateway for LLM apps

Use LLMs on sensitive text without sending the sensitive parts.

Veil swaps names, numbers and contact details for stand-ins before your prompt reaches the model, then puts the real ones back. On a public test set it catches most of them.

Integrate

    
Veil speaks the OpenAI chat format, so any client that lets you set a base URL works unchanged. It also runs as an MCP server for Claude Desktop.

  

    

      

      

    

    

      
Endpoints

        
POST/v1/chat/completions
Masks the messages, calls your model, restores the answer. Streaming supported.

        
POST/v1/mask
Pseudonymize text without calling a model.

        
POST/v1/unmask
Turn stand-ins back into real values for one session.

        
GET/audit/verify
Walk the hash chain and report the first broken entry.
